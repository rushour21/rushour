# Kill list

Written down so it stops being reconsidered. Adding anything here requires
deleting something already shipped.

- **Streaks and gamification.** Seductive, and it turns a missed day into a
  reason to quit rather than a data point. Drift detection replaces it.
- **A chat assistant.** Costs more, decides worse, and turns a 90-second screen
  into an open-ended conversation.
- **Nutrition, caffeine, alcohol, steps, strength-versus-cardio.** None of it
  changes a planning recommendation. Only sleep, energy and stress feed
  readiness, so only those three are collected.
- **Self-rated skill percentages.** People cannot rate themselves, and the
  number would drive real decisions.
- **Social feed, sharing, accountability partners.** A different product.
- **Infinite news scroll.** Directly self-defeating for an execution system.
- **Full OKR modelling** — key results, confidence scoring. A team methodology
  imported into a single-player tool.
- **Dopamine scores, productivity scores, any invented metric.** Every number
  shown must be traceable to something the user entered.
- **Native mobile apps.** Responsive web until phase 4 at the earliest.

## Deferred, not killed

Specified in `spec.html` and waiting on a gate: habit cue chains, sleep
consistency trends, monthly rollup, the skill map, the job pipeline, and the
information diet.
